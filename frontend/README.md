# ITDATA Frontend

Aplicación Angular para gestión y documentación de operaciones de TI.

## Requisitos

- Node.js 22 o 24 LTS recomendado.
- Backend Django disponible en `http://localhost:8000`.

## Desarrollo

```powershell
npm install
npm start
```

Abrir `http://localhost:4200`.

La URL del backend se configura en `src/environments/environment.ts`.

## Compilación

```powershell
npm run build
```
